# Communication at Microsoft

> Guidance, frameworks, and resources for effective communication within Engineering, Enablement, and Operations (EEO) -- with a focus on what a data scientist needs to communicate clearly, persuasively, and professionally.

---

## Why This Folder Exists

Communication is a force multiplier. The best analysis is worthless if the audience does not understand, trust, or act on it. This folder consolidates Microsoft's internal comms guidance, meeting frameworks, and presentation standards into a single reference so we can:

1. **Prepare** high-stakes meetings using structured frameworks (Meeting Map, Story Outline).
2. **Write** clear emails, Teams messages, and SharePoint posts that follow EEO standards.
3. **Present** data-driven insights with executive presence and accessibility.
4. **Improve** iteratively using the comms checklist before every send/publish/present.

## Data Scientist Communication Lens

As data scientists, our communication challenges are specific:

- **Translating technical findings** into business language for non-technical stakeholders.
- **Choosing the right level of detail** -- executives want the "so what," engineers want the "how."
- **Using data responsibly in comms** -- avoid drowning the message in numbers.
- **Active voice and actionable language** -- "Revenue declined 12% in Q3" not "A decline was observed."
- **Visual storytelling** -- charts and graphs that reinforce the narrative, not distract from it.

These documents encode Microsoft's internal standards so we can layer our data science expertise on top of a solid communication foundation.
