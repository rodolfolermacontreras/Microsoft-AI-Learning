# Sessions

> Learning sessions, Q&A notes, and exploration logs. Each session gets a dated entry with questions asked, answers found, and takeaways.

---

## How to Add a Session

1. Create a new file: `05-sessions/YYYY-MM-DD-topic.md`
2. Use the template below
3. Fill in as you go — these are working notes, not polished docs

---

## Session Template

Copy into `05-sessions/YYYY-MM-DD-topic.md`:

```markdown
# Session: [Topic]

**Date:** YYYY-MM-DD  
**Duration:** ~X hours  
**Focus:** What this session was about  

---

## Questions Going In
1. Question I wanted to answer
2. Another question

## What I Did
- Step-by-step notes of exploration
- What I tried, what worked, what didn't

## Answers Found
### Q1: [Question]
**Answer:** What I learned

### Q2: [Question]
**Answer:** What I learned

## Key Takeaways
- Bullet points of the most important learnings

## Follow-Up Items
- [ ] Thing to investigate next
- [ ] Thing to try

## Resources Used
- [Link to doc](URL)
- Notes from conversation with X
```
