# Projects

> Active Copilot Studio projects. Each project gets its own subfolder with a README, journal, and assets.

---

## How to Add a New Project

1. Create a subfolder: `04-projects/project-name/`
2. Add a `README.md` with the template below
3. Track progress in the project README or a separate journal file
4. Store related assets (screenshots, exports, configs) in the project folder

---

## Project Template

Copy this into `04-projects/your-project-name/README.md`:

```markdown
# Project: [Name]

## Overview
- **Goal:** What this project achieves
- **Agent type:** (Knowledge / Task / Workflow / Multi-agent / Autonomous)
- **Channel:** (Teams / Web / M365 Copilot / Multi-channel)
- **Status:** (Planning / In Progress / Testing / Deployed / Archived)
- **Started:** YYYY-MM-DD
- **Last updated:** YYYY-MM-DD

## Architecture
- **Orchestration:** Generative / Classic
- **Knowledge sources:** (list)
- **Tools:** (list)
- **Integrations:** (connectors, MCP servers, APIs)

## Design Decisions
| Decision | Choice | Rationale |
|---|---|---|
| Orchestration mode | Generative | Need flexible routing for ~20 tool types |

## Journal
### YYYY-MM-DD — Entry Title
What happened, what was learned, what's next.

## Open Questions
- [ ] Question 1
- [ ] Question 2

## Resources
- Link to agent in Copilot Studio
- Related docs
```
